# Changelog

## 1.2.0-rc.1
- Add WoW Forever 1.60.1 / Interface 16001 support.
- Preserve Classic Anniversary 2.5.6 / Interface 20506 and Classic Era 1.15.9 / Interface 11509 support.
- Add capability-based compatibility helpers in `Compat.lua`.
- Add a dedicated `Options.lua` settings module with persistent Show XP Bar and Show Pet Level preferences.
- Add Forever-specific purple pet XP styling and compact pet-level medallion while retaining the legacy Classic presentation on non-Forever clients.
- Add `/pxp options` and `/pxp debug`.
- Harden pet-frame anchoring, layer synchronization, and API access.
